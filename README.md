# .SÉQUENCE

Ton journal privé de films et de séries.

Tous les fichiers sont à la racine du dépôt, sans dossier :

```
index.html     la page du site
style.css      la charte (couleurs, typo, modes clair et sombre)
config.js      tes clés Supabase et TMDB
app.js         les pages et les actions
store.js       la sauvegarde (Supabase, ou navigateur en mode démo)
tmdb.js        la recherche de films (Wikidata) et séries (TVmaze), ou TMDB si une clé est ajoutée
demo-data.js   les exemples du mode démo
```

Mise en ligne : Settings > Pages > Deploy from a branch > main > / (root).

Films : Wikidata (CC0). Séries : TVmaze (CC BY-SA). Avec une clé TMDB : données et images TMDB.
